# Route

## 概要

英語を話せるようになりたい人に向けた架空の英会話学習サービスのWebサイトです。

## サイトURL

[Route](https://azma24.github.io/Route/)

## 使用技術

- HTML
- SCSS
- JavaScript
- Swiper

## 実装内容

- レスポンシブデザイン
- 固定ヘッダー・スクロール時の縮小
- ハンバーガーメニュー
- モーダルウィンドウ
- アコーディオン
- スクロール連動アニメーション
- Swiperによるスライダー
- OGP・favicon設定

## 対応デバイス

- PC
- タブレット
- スマートフォン
